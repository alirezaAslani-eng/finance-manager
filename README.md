# A user-dashboard developing with Next.js & MUI

## This website allows users to manage their transactions, they can use this it to see when and why they created a transaction 

**No Demo yet, still devloping** 🧑‍💻

## Features 🎉
- Creating two type of a transaction : income & expense and only edit or delete the latest one.
- Switching between accounts, each user's acconut has its own transactions and balance.
- Advanced filtering system includes parameters like date, amount, categories, accounts and more...
- Users can categorise their transactions by adding custom categories


## Clone and run this project:
```
git clone https://github.com/alirezaAslani-eng/finance-manager.git
npm install
```
