# Category APIs

## To Create

### **_url & method -------------------------------------->_**

`api/categories` & `POST`

### **_header -------------------------------->_**

```json
{ "Content-Type": "application/json" }
```

### **_body ------------------------------------>_**

```json
{ { "name":""}}
```

## To Delete

### **_url & method -------------------------------------->_**

`api/categories/:id` & `DELETE`

## To Edit

### **_url & method -------------------------------------->_**

`api/transactions/:id` & `PUT`

### **_header -------------------------------->_**

```json
{ "Content-Type": "application/json" }
```

### **_body ------------------------------------>_**

```json
{
  "name": ""
}
```
